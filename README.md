# GreenGrid

3D-Echtzeit-Simulation eines dezentralen Energienetzes mit Vite, React, React Three Fiber, Drei, Zustand und Tailwind CSS.

## Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## GitHub Pages (public deployment)

This app is published to GitHub Pages using GitHub Actions.

1. In GitHub, go to **Settings → Pages** and set **Source** to **GitHub Actions**.
2. Push changes to the `main` branch.
3. After the workflow succeeds, the app is publicly available at:

`https://merlin2lmml.github.io/GreenGrid-3D-Simulation/`
