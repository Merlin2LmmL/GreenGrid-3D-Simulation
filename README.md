# GreenGrid

3D-Echtzeit-Simulation eines dezentralen Energienetzes mit Vite, React, React Three Fiber, Drei, Zustand und Tailwind CSS.

## Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## GitHub Pages (public deployment)

Diese App wird über GitHub Actions auf GitHub Pages veröffentlicht.

1. In GitHub unter **Settings → Pages** bei **Source** auf **GitHub Actions** stellen.
2. Änderungen in den `main`-Branch pushen.
3. Nach erfolgreichem Workflow ist die App öffentlich erreichbar unter:

`https://merlin2lmml.github.io/GreenGrid-3D-Simulation/`
